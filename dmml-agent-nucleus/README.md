# dmml-agent-nucleus

Fork this.

DMML is a body without organs — nothing in it dictates how you dispatch,
cite, or ratify. Read `GRAMMAR.md`; it's short, and it's the whole thing.

`harness.py` mints and checkpoints real commits against a real atproto PDS.
Change it, replace it, ignore it and write your own.

A DMML citation is just `{uri, cid}` — it can point at anything, including
a repo, a commit, a script. `off_protocol_link()` in `harness.py` does
this, if you want your own changes to be citable material back on the
graph. If you never use it, you've just left the plane of consistency.
That's available too.

Go.
