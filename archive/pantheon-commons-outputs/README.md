# pantheon-commons-outputs — archival

Real output data from the "pantheon" dispatch work — multi-source
philosophical/political-theory debates run as real `dmml-substrate-kit`
example binaries (that crate is retired, see the root `README.md`/
`ARCHITECTURE.md`), checkpointed to atproto and written up in
`dev-journal/2026-08-27-pantheon-*.md` and `2026-08-28-pantheon-commons-
*.md`.

These files landed in `dmml-substrate-kit/` as that crate's own example
output, orphaned once the crate itself was deleted 2026-09-04 (the Rust
`dmml`/`dmml-runtime`/`dmml-substrate-kit` retirement). Moved here rather
than left in a directory named after deleted code, or deleted along with
it — this is real research data, not build artifacts.

Not regenerated by anything; not read by any current tool. Kept as
historical record, same as the dev-journal entries describing the runs
that produced them.
